🔍 TapWord — Scroll Edge-Case Manual Tests

Issue #35 · Tooltip scroll-drift fix verification · Load each page with the TapWord extension installed, then follow the on-page instructions.

How to use:
  1. Install the TapWord Translator extension (load unpacked from dist/).
  2. Open any test file via File → Open in Chrome (file:// URLs work).
  3. Select / double-click a highlighted word to trigger a translation tooltip.
  4. Scroll the page (or the inner container) and observe whether the tooltip drifts.
  5. Each page has a banner describing the PASS / FAIL criteria.
01 Baseline
Normal Window Scroll
normal-window-scroll.html
Standard <!DOCTYPE html> page. window.scrollY accumulates. Tooltip should follow its anchor word as you scroll.
✅ EXPECTED: Tooltip stays below anchor word while scrolling
02 Issue #35
Body Scroll Container
body-scroll-container.html
Reproduces the OpenAI Docs layout. <body> has position:relative; overflow-y:auto; height:100vh. window.scrollY stays 0; body.scrollTop accumulates. This was the broken case before the fix.
✅ EXPECTED: Tooltip stays below anchor word (no upward drift)
03 Quirks Mode
Quirks Mode (No DOCTYPE)
quirks-mode.html
No <!DOCTYPE> — Chrome enters Quirks Mode. body.scrollTop mirrors window.scrollY, creating a double-counting risk if the guard condition is absent.
✅ EXPECTED: No double-drift — tooltip moves at 1× speed, not 2×
04 Inner Scroll
Inner Div Scroll Container
inner-div-scroll.html
A fixed-height <div> with overflow-y:scroll contains the text. Neither the window nor <body> scroll.
✅ EXPECTED: Tooltip stays below anchor word while inner div scrolls
05 Iframe
Iframe Coordinate Isolation
iframe.html + iframe-inner.html
An <iframe> loads iframe-inner.html, which has scrollable translatable text. Tooltip must use the iframe's coordinate system, not the outer page's.
✅ EXPECTED: Tooltip appears inside iframe at correct position
06 RTL
RTL Body Scroll
rtl-body-scroll.html
Same body-scroll layout as test 02 but with dir="rtl". Tests that horizontal scroll offset (scrollLeft) is computed correctly under RTL + body-scroll conditions.
✅ EXPECTED: Tooltip appears at correct horizontal position below anchor
07 Multi-Scroll
Multiple Scroll Regions
multiple-scroll-regions.html
Body-scroll region and an inner div scroll region coexist. One word lives in each region. Both tooltips must stay anchored independently.
✅ EXPECTED: Both tooltips stay anchored to their respective words
