Overview

The configuration file lets you specify global instructions for every task your agent performs in this repository.

Place it at the root of your project, or inside a .codex/ directory. The agent reads this file at startup and uses its contents as persistent context.

Syntax

Each line beginning with a # character is treated as a comment and ignored by the parser. All other non-blank lines are forwarded verbatim to the language model as part of the system prompt.

Markdown headings, bullet lists, and fenced code blocks are rendered as plain text, so you can use any formatting style you find readable.

Scope

Instructions defined here apply to every conversation in the current workspace. You can override them per-conversation by adding inline instructions at the top of your prompt.

If both a root-level file and a .codex/ file exist, their contents are merged in order: root file first, then the directory file.
