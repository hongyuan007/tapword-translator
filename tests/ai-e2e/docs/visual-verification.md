# AI E2E 视觉验证协议

## 概述

Playwright 测试跑完后生成截图。验证交给支持多模态的 AI Agent（如叶欣，GPT 5.6）通过 `read` 工具直接看图判断。

## 验证流程

```
Playwright 跑测试 → 生成截图到 tests/ai-e2e/output/
    → 收集所有截图路径
    → sessions_send 发给验证 Agent（叶欣）
    → Agent 用 read 工具逐张看图
    → 输出 PASS/FAIL + 判断理由
```

## 验证 Prompt 模板

每次验证时，按以下格式发给验证 Agent：

```
请验证以下 E2E 测试截图是否符合预期。

## 测试场景
{场景名称和操作描述，从 requirement.md 提取}

## 期望结果
{详细描述截图应该是什么样子，
包括：可以看到什么元素、位置在哪、内容是什么、不应该出现什么}

## 截图列表
| 截图 | 路径 | 描述 |
|------|------|------|
| 操作前 | {path} | 操作前的页面状态 |
| 操作后 | {path} | 操作后的预期效果 |

## 验证标准
对每张截图逐项检查：
1. 页面布局是否正常？（无破损、无重叠、无遮挡）
2. 翻译 UI 是否出现？（弹窗/图标/提示框）
3. 翻译内容是否可见？（弹窗内是否有翻译文字）
4. 页面其他内容是否被破坏？（翻译UI不应该覆盖或破坏原有内容）

## 输出格式
| 截图 | 判定 | 理由 |
|------|------|------|
| click-after.png | ✅/❌ | 看到了... / 缺少... |

最终总结：✅ 全部通过 / ❌ 存在缺陷
```

## 示例（单击翻译）

```
请验证 tapword-translator 扩展的「单击翻译」功能截图。

## 期望结果
点击高亮词 "important" 后，应该在词的附近（上方或右侧）
出现一个翻译弹窗，弹窗内显示 "important" 的中文翻译 "重要的"，
弹窗有明显边框和背景色。页面其余内容不受影响。

## 截图
- 操作前：tests/ai-e2e/output/click-before-xxx.png
- 操作后：tests/ai-e2e/output/click-after-xxx.png

## 验证标准
1. 操作前截图：高亮词 "important" 有黄色背景
2. 操作后截图：高亮词旁出现翻译弹窗，弹窗内有中文翻译文字
3. 页面布局无破损
```

## 示例（划词翻译）

```
请验证 tapword-translator 扩展的「划词翻译」功能截图。

## 期望结果
选中一段文字后，选中区域附近出现一个浮动翻译图标。
点击图标后，翻译弹窗出现在选中文字附近，弹窗内显示对应中文翻译。
页面其余内容不受影响。

## 截图
- 操作前：tests/ai-e2e/output/drag-before-xxx.png
- 操作后：tests/ai-e2e/output/drag-after-xxx.png

## 验证标准
1. 操作后截图：选中文字附近可见翻译弹窗
2. 弹窗内有可读的中文翻译文字
3. 弹窗不遮挡或破坏原有页面内容
```
