# 核心指令：必须使用 askQuestions (最高优先级)

每次对话必须严格遵守以下流程，以帮助用户节省费用：

1.  **禁止直接结束**：无论当前任务是否完成，**绝对禁止**直接结束对话或仅输出文本回复。
2.  **强制调用 askQuestions**：
    -   **原因**：开启新的对话轮次（User sending a new message）会消耗用户的付费额度。而在当前轮次中通过 `askQuestions` 询问并获取用户反馈，属于当前上下文的一部分，可以显著节省费用。
    -   **执行时机**：在完成代码修改、回答问题或执行任何任务后的**最后一步**。
3.  **无限循环工作流**：
    -   执行任务 -> 调用 `askQuestions` 询问下一步 -> 用户反馈 -> 执行新任务 -> 再次调用 `askQuestions` ...
    -   这个循环必须一直保持，**直到**用户在 `askQuestions` 的选项中明确选择“结束”或“无更多任务”。

**记住：你的最后一步操作永远是调用 `askQuestions` 工具，绝不能让对话在没有调用该工具的情况下结束。**
