# 行业调研：同类产品词汇等级标注方式

> 调研时间：2026-06-14
> 调研目标：了解主流词典/翻译产品如何展示词汇等级标注，为 tapword-translator issue #62 提供设计参考。

## 核心结论

**国内主流词典产品（有道、欧路、金山词霸）普遍已在查词结果页以标签（tag/badge）形式展示词汇所属考试等级（高考/四级/六级/考研/专四/专八/雅思/托福/GRE），而国际权威学习型词典（朗文、牛津、柯林斯、剑桥）则采用语料库词频分级体系（CEFR、Collins星级、Longman 9000 等）。两类体系的交集是：用户最关心的信息是「这个词属于哪个考试范围」以及「这个词有多常用」。UI 展示方式以轻量级彩色标签/图标为主，放置在单词释义页头部区域，音标附近。**

---

## 产品逐一分析

### 1. 有道词典（网易有道）

- **词汇等级：是**，展示以下等级体系：
  - 国内考试：中考、高考、四级（CET4）、六级（CET6）、考研、专四（TEM4）、专八（TEM8）
  - 国际考试：雅思（IELTS）、托福（TOEFL）、GRE、GMAT、SAT、BEC
  - 教材分级：初中、高中、大学

- **UI 展示方式**：
  - 在查词结果页（释义页）**单词头部区域**，音标下方，以**彩色标签（tag/badge）**形式展示
  - 标签形如「四级」「六级」「考研」「高考」「雅思」「托福」等
  - 不同标签使用不同颜色区分（考试类用一种色系，词根词缀用另一种色系）
  - 有道曾做「分级标签」优化升级：通过不同标签标注单词难度，并匹配精选例句，帮助学生有针对性地备考（来源：品玩报道）

- **数据来源**：自有词库，基于有道教育团队维护的考试大纲词汇表。有道背单词模块拥有完整的各考试词库（四级、六级、考研、雅思、托福、高考、中考、BEC 等），与查词结果页等级标签共用同一数据源。

- **用户评价**：
  - 用户普遍认可标签的存在价值，尤其是备考用户会根据标签快速判断单词是否需要重点记忆
  - 部分用户反映部分单词的等级标注不够准确（如某些标注为「四级」的词实际已属高中词汇范围）
  - 有道的「派生串记」功能会将同词根的单词串联展示，等级标签帮助用户理解词汇难度递进关系

### 2. 欧路词典

- **词汇等级：部分支持**，自带词库有基础等级标注，但精度存疑：
  - 自带词库标注国内考试等级（四级、六级、考研、高考等）
  - 支持加载第三方 MDX 词典，不同词典有不同的等级标注体系
  - 支持 Collins、朗文等权威词典，这些词典自带词频分级系统

- **UI 展示方式**：
  - 在查词结果页，**释义文本内联展示**等级标签
  - 标签形式取决于加载的词典：自带词典使用文字标注（如「CET4」「CET6」），第三方 MDX 词典则按词典自身的 HTML 模板渲染
  - 生词本支持按「等级」排序查看
  - 支持荧光笔高亮功能，用户可手动标记重点

- **数据来源**：
  - 自带词库：自有整理的考试词汇表
  - 第三方词典：社区制作的 MDX 词典（如 skywind3000/ECDICT 简明英汉增强版，包含 Collins 星级 + Oxford 3000 + 考试标签 + BNC/COCA 词频）

- **用户评价**：
  - FreeMdict 论坛用户反馈：「欧陆那个自带的感觉不准」，反映自带词库的等级标注准确性不足
  - 高级用户倾向加载第三方 MDX 词典（如 ECDICT 增强版）来获取更准确的等级信息
  - 社区存在强烈需求：有用户专门发帖询问「有没有人做过专门反映考试类别的 mdx 词典，能显示四六级、托福雅思、GRE 这些级别」

### 3. 金山词霸（爱词霸）

- **词汇等级：是**，但展示方式偏重于学习/背单词模块：
  - 展示等级：四级、六级、考研、雅思、托福、GRE、GMAT、SAT、BEC 等
  - 查词结果页集成了 Collins 高阶词典内容，带有 Collins 星级词频标注
  - 背单词模块（爱词吧）有完整的考试词汇课程分类

- **UI 展示方式**：
  - 查词结果页：Collins 词典内容区域会展示 Collins 星级（红色圆点 ●，1-5 星）
  - 背单词模块：以课程列表形式展示各考试等级词汇书
  - 整体偏向传统布局，等级标注不如有道突出

- **数据来源**：
  - Collins 词典授权（Collins COBUILD Advanced Learner's Dictionary）
  - 自有考试词汇表
  - 柯林斯星级来自 Collins 语料库统计

- **用户评价**：
  - 金山词霸近年在查词功能上的创新较少，用户群体有所流失
  - Collins 星级词频标注被认为是有价值的信息，但用户更倾向直接使用有道或欧路获取更全面的标注

### 4. MDict / MDX 词典生态

- **词汇等级：取决于加载的词典文件**，MDict 本身是开放平台：
  - 软件本身不提供词汇等级标注
  - 等级信息完全取决于用户加载的 MDX 词典文件
  - 社区制作的词典文件覆盖多种等级体系

- **UI 展示方式**：
  - 完全由 MDX 词典文件内部的 HTML/CSS 模板决定
  - 常见形式：在释义末尾以括号或标签形式展示（如 `[CET4]` `[CET6]` `[GRE]` `[TOEFL]`）
  - ECDICT 增强版（最受欢迎的社区词典之一）的展示方式：
    - 释义末尾标注：`-K2` （K = Oxford 3000，2 = Collins 二星）
    - 考试标签：`cet4` `cet6` `ky`（考研）`gk`（高考）`toefl` `ielts` `gre`
    - 词频数据：COCA 排名 + BNC 排名数字

- **数据来源**：
  - **ECDICT（skywind3000）**：开源词库，整合了 Collins 星级、Oxford 3000、考试大纲词汇、BNC/COCA 词频
  - 社区词典制作者根据考试大纲手动整理
  - 部分词典从正版授权词典转换而来

- **用户评价**：
  - 高级用户非常依赖 MDict + ECDICT 组合获取最全面的词汇等级信息
  - ECDICT 的等级标注被社区认为比欧路词典自带的更准确
  - 社区对「同时包含国内外考试等级 + 语料库词频」的词典需求强烈

### 5. 朗文当代高级英语辞典（Longman LDOCE）

- **词汇等级：是**，使用自有的 Longman Communication 9000 体系：
  - 第六版从原来的 3000 核心词扩充为 **Longman Communication 9000** 进阶体系
  - 分为三个层级，用**红色圆点**标注：
    - ●●●：最常用 1-3000 词
    - ●●：常用 3000-6000 词
    - ●：次常用 6000-9000 词
  - 另有 **S（Spoken）** 和 **W（Written）** 口语/书面语频率标注：
    - S1/S2/S3 = 口语最常用 1000/2000/3000 词
    - W1/W2/W3 = 书面语最常用 1000/2000/3000 词
  - 第六版特别标注了与**高考、四六级、考研**词汇的对应关系
  - App Store 描述中提到：「多种词频标注满足不同学习需求，特别标注课标及欧框等级」

- **UI 展示方式**：
  - 在单词词条目头部，音标旁边以红色圆点 ● 和 S/W 字母标注
  - 视觉上非常醒目，不干扰阅读

- **数据来源**：朗文自有语料库（Longman Corpus Network），基于真实语料统计分析

- **用户评价**：
  - 朗文的 S/W 口语/书面语分开标注是**独创**，被认为比单纯频率排名更有学习价值
  - 9000 词分级体系被教师和学习者广泛认可
  - 红点标注方式简洁直观，不干扰阅读体验

### 6. 牛津高阶英语词典（Oxford OALD）

- **词汇等级：是**，使用 Oxford 3000/5000 + CEFR 体系：
  - 第 10 版引入 **Oxford 3000** 和 **Oxford 5000** 词表
  - 每个词都标注了 **CEFR 等级**（A1-C1）：
    - A1（Beginner）/ A2（Elementary）
    - B1（Intermediate）/ B2（Upper-Intermediate）
    - C1（Advanced）
  - Oxford 3000 覆盖 A1-B2，Oxford 5000 扩展到 C1
  - 用**钥匙符号 🔑** 标注 Oxford 3000/5000 核心词汇

- **UI 展示方式**：
  - 单词旁标注钥匙符号 + CEFR 等级字母（如 `🔑 B1`）
  - 简洁清晰，国际通用标准

- **数据来源**：Oxford English Corpus（牛津英语语料库）+ CEFR 国际标准

### 7. 柯林斯高阶词典（Collins COBUILD）

- **词汇等级：是**，使用 Collins 五星词频体系：
  - 基于语料库统计，选出最常用的 14,700 个单词，分为 5 个频段：
    - ★★★★★（5星）：最常用约 700 词
    - ★★★★（4星）：约 1,200 词
    - ★★★（3星）：约 1,500 词
    - ★★（2星）：约 3,200 词
    - ★（1星）：约 8,100 词
  - 这 14,700 词覆盖了 95% 的日常口语和书面英语

- **UI 展示方式**：
  - 在词条旁边以**红色圆点**形式展示星级（早期版本用星号 ★）
  - 金山词霸、欧路词典加载 Collins 词典后也会展示此标注

- **数据来源**：Collins Corpus（柯林斯语料库，数十亿词汇规模）

### 8. 百度翻译 / 必应词典

- **词汇等级：基本不展示**：
  - 百度翻译查词结果主要展示释义、例句，**不标注考试等级**
  - 必应词典同样不提供词汇等级标注
  - 百度翻译的词典模块收录了 Collins、牛津内容，间接可看到 Collins 星级
  - 主要面向翻译场景而非学习场景，词汇等级标注不是产品重点

## 对比总结表

| 产品 | 等级体系 | UI 形态 | 数据来源 | 用户评价 |
|------|---------|---------|---------|---------|
| **有道词典** | 高考/四级/六级/考研/专四/专八/雅思/托福/GRE/SAT/BEC | 彩色标签（badge），释义页头部 | 自有考试词库 | 备考用户高度依赖，部分标注准确性存疑 |

| **金山词霸** | Collins 五星 + 国内考试 | Collins 红色圆点，考试分级在背单词模块 | Collins 授权 + 自有词库 | Collins 标注有价值，整体创新不足 |
| **MDict/MDX** | 完全取决于词典文件 | HTML 模板自定义 | 开源（ECDICT 等）/社区制作 | 高级用户首选，信息最全面 |
| **朗文 LDOCE** | Longman 9000（红点 1-3 颗）+ S/W 口语书面语分级 | 红色圆点 + S/W 字母 | 自有语料库 | 口语/书面语分离标注是独创，教师推崇 |

| **百度翻译** | 基本无 | — | — | 非学习型产品，用户不期待此功能 |
| **必应词典** | 基本无 | — | — | 已不活跃 |

## 对 tapword-translator 的启发

### 1. 国内考试等级标注是核心需求，不是可选功能

有道词典作为行业标杆已经验证了用户需求：**中国用户在划词翻译时，看到生词的第一反应是「这个词属于哪个考试范围」**。建议 tapword-translator 在翻译结果面板中以轻量标签形式展示高考/四级/六级/考研/雅思/托福/GRE 等等级，与有道形成对标。

### 2. UI 展示建议：彩色 badge，放在音标附近

行业通用的做法是在**释义区头部、音标旁边**放一个或多个彩色小标签（badge），而非嵌入释义文本中。建议：
- 标签颜色按等级难度渐变（如：高考=浅蓝、四级=蓝色、六级=深蓝、考研=紫色、雅思/托福=橙色、GRE=红色）
- 标签字体小、不抢眼，但可点击查看详情
- 支持 hover 显示简短说明

### 3. 数据源推荐：ECDICT 开源词库

skywind3000/ECDICT 是目前最成熟的开源英语词库，已整合：
- Collins 星级（1-5 星）
- Oxford 3000 标记
- 国内考试标签（cet4/cet6/ky/gk/toefl/ielts/gre）
- BNC/COCA 词频排名

可直接作为 tapword-translator 的词汇等级数据源，无需从头构建。数据以 CSV 格式开源，字段 `tag` 中包含所有考试标签。

### 4. 双轨制标注：考试等级 + 语料库频率

朗文（9000 词 + S/W 标注）和牛津（CEFR）的成功经验表明，**考试等级和语料库频率是互补信息**：
- 考试等级回答：「这个词在我的考试范围内吗？」
- 频率信息回答：「这个词在实际使用中常见吗？」

建议 tapword-translator 同时展示两类信息：主标签为考试等级（国内用户最关心），辅助信息为 Collins 星级或 CEFR 等级（国际通用标准）。

### 5. 避免欧路词典的教训：标注准确性是生命线

欧路词典自带词库的等级标注被用户评价为「感觉不准」，这是一个重要警示。如果标签标注错误（如把考研核心词标为四级），会直接损害用户信任。建议：
- 以 ECDICT 的考试标签为基准（社区验证多年）
- 对边界词汇（同时属于多个考试等级的词）取最高等级展示
- 提供「数据反馈」入口，允许用户报告标注错误
