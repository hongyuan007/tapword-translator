### Task Objective
This changeset adjusts the full-page translation module to better detect the real content container during simple paragraph translation.

The specific goal is:

1. Preserve the existing benefit of `unwrapDeepestOnlyHTMLChild()` for nested wrapper chains such as `div > div > div > text`.
2. Avoid over-unwrapping block-like content containers into a single inline leaf such as `div[data-testid="tweetText"] > span`.
3. Make bilingual translation more likely to render on a new line for正文内容块 while keeping inline UI cases unchanged.
