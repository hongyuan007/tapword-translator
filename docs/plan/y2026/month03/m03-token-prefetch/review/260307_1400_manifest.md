### Task Objectives
This task attempted to reduce first-translation latency by proactively refreshing the JWT token as soon as a content script is injected into a page — before the user performs any selection or translation. The approach wakes up the background service worker early via a `PAGE_ACTIVATED` message, which then kicks off a non-blocking `getToken()` call in `AuthService`. Additionally, a pre-existing silent bug in `AuthService.startAutoRefresh()` — where the `else` branch did not call `getToken()` when no token was present — was identified and corrected as part of this task.
